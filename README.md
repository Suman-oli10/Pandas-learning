# Pandas Learning — Fundamentals & Practice

This repository contains my Pandas tutorials, code examples, and practical exercises developed while learning Python data analysis. The goal is to strengthen my understanding of data manipulation and build a foundation for data science.

## About This Repository

This repository documents my learning journey with Pandas, from basic DataFrame operations to data filtering, sorting, and transformation using practical datasets.

## Topics Covered

- **Introduction to Pandas:** DataFrames, rows, columns, and indexes
- **Data Exploration:** `head()`, `tail()`, `info()`, `describe()`, and unique values
- **Reading Data:** Loading CSV, Excel, and Parquet files
- **Data Selection:** `loc[]`, `iloc[]`, `at[]`, and `iat[]`
- **Sorting and Filtering:** Sorting values and applying conditional filters
- **Data Manipulation:** Adding, removing, and renaming columns
- **Data Transformation:** `apply()`, lambda functions, and conditional operations
- **Working with Dates:** Datetime conversion and extracting date components
- **Exporting Data:** Saving DataFrames to CSV files

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Suman-oli10/Pandas-learning.git
```

Navigate to the project directory:

```bash
cd Pandas-learning
```

Install the required libraries:

```bash
pip install pandas numpy openpyxl pyarrow
```

Open `pandas_tutorial.ipynb` in Visual Studio Code or Jupyter Notebook to explore and run the examples.
